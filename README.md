# 读书总结

把整本书读薄，再写回一篇能一口气读完的长文。每本书两份文件：

- `.md`：Markdown 原稿
- `.html`：全内联样式，用浏览器打开后整段选中，可直接粘贴进微信公众号编辑器

## 结构

每篇沿用同一套骨架：一句话核心 → 这本书解决什么问题 → 全书骨架 → 逐章方法 → 最值得带走的洞见 → 阅读建议与局限 → 结语引原文收尾。
